# Security Policy

## Scope

This repository combines Telegram channel-copying utilities with a separate informational account-recovery guide. It is not affiliated with Telegram.

## Sensitive material

Please do not submit Telegram login codes, phone numbers, API hashes, Two-Step Verification passwords, session files, .tgback files, or backup QR codes in issues or pull requests. A valid session export can grant account access.

## Recovery

The recovery guide prioritizes official Telegram documentation and support. Third-party tools are linked for reference only and are not bundled or run by this project.

## Reporting

For a security concern, open an issue describing the affected component without including secrets or account credentials. If a secret was exposed, revoke the affected session or credential immediately and use official Telegram security settings.
