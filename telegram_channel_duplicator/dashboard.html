DANGER ZONE

Revoke recovery session

Logs out this dedicated session from Telegram. Every backup of this session will stop working. Your separate mirroring session is not revoked.

BEFORE YOU BEGIN

Protect your way back in

  1. 01
    Connect securely

    Use a trusted HTTPS Relay instance and your own credentials from my.telegram.org.

  2. 02
    Store backups separately

    Keep the encrypted file or QR and its unique password in separate, protected places.

  3. 03
    Verify periodically

    Sessions can expire or be revoked. Verify access and create a fresh backup when needed.

Session backups are sensitive

Server administrators can access the stored Telegram session and API credentials. Without a valid backup or Telegram-approved verification, Relay cannot recover an account or bypass two-step verification.

BACKUP FORMAT
Authenticated by design

Relay uses AES-256-GCM with scrypt. Legacy .tgback files are not compatible; they use an unsafe legacy format.
