Security rules

Never give anyone your Telegram login code, Two-Step Verification password, or an exported session file. A valid session file can give another person control of your account.
  • Use official Telegram support and your mobile carrier for number/SIM recovery.
  • After regaining access, review Settings → Devices and terminate sessions you do not recognise.
  • Enable Two-Step Verification and secure its recovery email.
  • Do not upload session files, QR backups, API hashes, or passwords to this website or an issue tracker.
  • Third-party projects are not endorsed by Telegram. Review source code and releases before running them.
TeleBridge Toolkit is an independent community project and is not affiliated with Telegram. Recovery outcomes depend on your access to the phone number, an existing session, and Telegram's security controls. This page provides guidance, not a guarantee of recovery.
