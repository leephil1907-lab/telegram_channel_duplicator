# Account Recovery Security

- Never request, store, log, or transmit Telegram login codes, 2-Step Verification passwords, session files, or backup QR codes.
- Treat .session, .tgback, and equivalent session exports as credentials capable of granting account access.
- Do not add an automated login, session-import, or account-takeover flow to the channel-duplication app.
- Prefer Telegram's official FAQ and support routes for recovery.
- If users choose third-party utilities, send them to the upstream repository and advise them to inspect releases, source, dependencies, and security posture before use.
- This project is independent and is not affiliated with Telegram.
